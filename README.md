# Gather

A small colony sim. Three settlers wake up in the wild with nothing. Order
them to chop trees, break rock and gather berries and reeds, then build walls,
beds, a campfire and farms before the cold nights get them.

Play it: https://milosarcade.com/gather/

## Controls

| Key | Action |
|---|---|
| 1 | Info: click a settler or tile to inspect it |
| 2 / 3 / 4 | Chop, Mine, Gather: drag over trees, rocks, bushes and reeds |
| 5 | Cancel orders, or mark a building for tear-down |
| W S D F | Wall, Stone Wall, Door, Floor |
| B C P K | Bed, Campfire, Farm, Stockpile |
| T / R | Temperature and room overlays |
| Space | Pause |
| + / - | Speed up or slow down |
| Scroll, arrow keys | Zoom and pan. 0 fits the whole map |
| Esc | Back to Info |

## Tips

- Resources only count once they're hauled to a stockpile, and settlers eat from it.
- An enclosed room with a door holds in heat. Stone walls hold far more than wood.
- A campfire warms, lights and cooks, and settlers keep it fed with wood.
- Farms need dirt or grass and take about a day and a half to grow.

Your colony saves in the browser, so you can come back to it later.

A single HTML file, no build step. Served with GitHub Pages.
